# FlowPilot: Smart Workflow Automation

**Tagline:** Automate the busywork. Keep control.

## Short description
FlowPilot is a web app that lets business teams build automated workflows without writing code. You connect your apps, drag steps into a visual builder, and watch every run as it happens. When something fails, you see what went wrong and retry in one click.

## Long description
Teams lose hours every week on repetitive tasks like following up on leads, approving invoices, and routing support tickets. FlowPilot turns these into workflows that run on their own. Each workflow is built from three kinds of steps: a **trigger** (what starts it), a **condition** (what it checks), and an **action** (what it does).

The interface is clean and friendly, with pastel workflow cards, clear status labels, and plain-language names, so operations teams can use it without technical help.

## Key features
- **Visual workflow builder:** add, edit and connect trigger, condition and action nodes on a canvas.
- **Workflow library:** browse workflows as cards, filter by team, sort by success rate, and preview any workflow with Quick view.
- **Test queue:** add several workflows to a queue and run them all as tests.
- **Integration hub:** connect business apps such as Salesforce, Slack, Gmail, Stripe and Zendesk.
- **Execution monitor:** see every run with its status, duration and step-by-step timeline.
- **Failure alerts:** failed runs are flagged on the dashboard with a clear error message and a Retry button.
- **Analytics:** track success rate over time and see which workflows run the most.
- **Settings:** manage your profile, alert preferences and API key.

## Who it's for
Operations, sales, finance and support teams who want to automate routine work and trust it, without waiting on developers.

## Design approach
- **Style:** a playful storefront-inspired look with large rounded cards, pastel tiles, and pill buttons.
- **Palette:** navy and violet accents on white and light-grey backgrounds.
- **Type:** Inter throughout.
- **Usability:** status shown with color and text, error messages that say what to do next, keyboard focus states, and a responsive layout for desktop and mobile.

## Tech note
This is a front-end prototype built with HTML, CSS and JavaScript, using sample data. For a full product, the next steps are a React + Node/Express backend with a database, login with JWT/OAuth, and a queue for running workflows.
